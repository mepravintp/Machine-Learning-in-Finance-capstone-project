# NovaFin capstone workspace

Run the notebooks in `notebooks/` in numeric order. Each saves a small result file in `results/`; notebook 10 combines them.
Requirements: Python 3.10+, pandas, numpy, scikit-learn, matplotlib, seaborn, shap, scipy, statsmodels, nbformat.
Install with: `pip install pandas numpy scikit-learn matplotlib seaborn shap scipy statsmodels jupyter`.
See `PROGRESS.md` for status, decisions, results so far, and how to resume in a new chat.
